# Identidade visual própria — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development ou superpowers:executing-plans.

**Goal:** Dar ao Atendimento uma identidade visual própria (ADR-10), dark-only, moderna e densa, aplicada em todas as telas existentes sem mudar comportamento.

**Architecture:** Um arquivo de tokens (`src/tema.css`) com escala de superfícies, texto, marca e semânticas; uma camada de componentes de UI em `src/components/ui/`; as telas passam a compor esses componentes em vez de escrever utilitários soltos.

**Tech Stack:** TailwindCSS v4 (tokens via CSS variables), @fontsource (IBM Plex Sans/Mono), lucide-react.

## Global Constraints

- **Dark-only.** Nada de tema claro.
- **Cores sólidas, sem gradiente. Sem emoji.** Ícones só `lucide-react`. (regras globais do usuário)
- **Azul do painel (`#0078d4`) como cor principal**, usado com parcimônia: ação, seleção, foco.
- **Comportamento não muda.** Nenhuma regra de negócio, query ou fluxo é alterado nesta etapa. Testes seguem passando sem edição.
- **Densidade:** UI base em 13–14px, linhas de lista compactas, respiro vindo de ritmo consistente e não de espaço vazio.
- **Acessibilidade:** contraste mínimo AA para texto; foco visível em tudo que é interativo; `aria-label` preservado nos testes existentes.

## Conceito

"Console de atendimento": instrumento de trabalho. Hierarquia por **camadas de superfície** (não por bordas em tudo), tipografia técnica (IBM Plex), status como **ponto colorido**, mono para dados (protocolo, telefone, hora). Transições curtas (120–160ms), sem animação decorativa.

## File Structure

- `src/tema.css` — Create: tokens (superfícies, texto, marca, semânticas, raio, sombra, foco)
- `src/index.css` — Modify: importar fontes + tema, base tipográfica, scrollbar
- `src/components/ui/Botao.tsx` — Create: variantes primario/neutro/perigo/fantasma, tamanhos
- `src/components/ui/Campo.tsx` — Create: Input, Textarea, Select com rótulo e foco consistentes
- `src/components/ui/Modal.tsx` — Create: substitui o AdminModal (overlay, escape, foco)
- `src/components/ui/Selo.tsx` — Create: badge e PontoStatus
- `src/components/ui/Tabela.tsx` — Create: casca de tabela densa
- `src/components/ui/Estados.tsx` — Create: Vazio, Carregando (skeleton), Erro
- Telas: `Login`, `Layout`, `Admin` + 7 abas, `Inbox` (3 componentes) — Modify: compor os novos componentes
